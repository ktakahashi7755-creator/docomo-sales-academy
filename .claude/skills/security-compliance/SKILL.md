# Security & Compliance

`CLAUDE.md` §3 を正典に要約。**1件でも🔴があればマージ不可。**

## 秘密情報
- `service_role` キー・AIプロバイダの API キーを**フロントに出さない**。フロントは anon キーのみ。
- 秘密はサーバー側（Supabase Edge Function 等）の env に置く。`VITE_*` に秘密を入れない（VITE_ はクライアントに露出する）。
- ビルド出力（dist）に鍵が含まれないことを確認する。

## アクセス制御
- 個人情報・学習者データは RLS で**本人/権限者のみ**に限定。UI で隠すだけにせず RLS で実防御（二重防御）。
- 越権（trainee が他人のデータ取得、SV が編集権限を越える等）を作らない。

## コンプライアンス（販売現場の原則）
- **パスワード・認証コードは「お客様自身が入力」を原則**とする文言・フローを崩さない。代理入力を促す導線を作らない。

## 監査ログ
- 主要操作（role 変更・商材編集・認定承認等）は `audit_logs` に記録。**書込はサーバー側関数/Edge Function**（フロントから直接 insert しない）。`audit_logs` の読み取りは admin のみ。
