## 出典・鮮度管理

- 各 `products.official_url` と `products.official_checked_at`（YYYY-MM-DD）を正とする。
- `official_checked_at` から **90日超で鮮度警告**（Phase 2 の管理画面と連動）。
- 値を更新したら確認日も更新し、`product_versions` に before/after を記録。

## 不明値の扱い

- 確定できない料金・補償・仕様は**それらしい数字を置かない**。
- UI に「**要確認**」を表示し、本 docs と `docs/AUDIT.md` に TODO を残す。
- 判断に迷う事実は止めて高橋に確認する。
