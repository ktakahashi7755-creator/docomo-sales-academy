# 引き継ぎ：カリキュラム知識のブラッシュアップ依頼（ChatGPT用）

> このファイルは **そのままChatGPTに貼って使う引き継ぎ資料** です。
> 目的は「Provide Growth Academy（携帯・通信の販売育成アプリ）」の**カリキュラム知識を、未経験からドコモ販売クローザーを目指せる水準まで深く・正確にブラッシュアップする**こと。
> 最後の「ChatGPTへの依頼」と「返してほしい形式」をそのまま指示として使ってください。

---

## 0. ChatGPTへ渡すときの前置き（コピー用）

```
あなたは携帯・通信業界（ドコモ）の販売研修を設計するトッププロです。
これから渡す「現状のカリキュラム」と「商材の正典データ（公式リンク付き）」をもとに、
未経験者がドコモ販売クローザーを目指せる水準まで、各レッスンの知識を深く・正確に
ブラッシュアップしてください。守るルール（捏造禁止・コンプライアンス）と、
返してほしい出力形式は本文末尾に指定しています。
```

## 1. プロダクト概要

- 名称：**Provide Growth Academy**（プロバイド株式会社の販売育成Webアプリ）
- 対象：携帯・通信販売の**未経験ヘルパー〜認定クローザー**
- 学びの道筋：座学 → 確認テスト → トークスクリプト → ロープレ（AI評価）→ 認定
- カリキュラムは **5ステップ・全19レッスン**（下表）。各レッスンは下記のデータ構造を持つ。

## 2. レッスンのデータ構造（この形で深掘りしてほしい）

各レッスンは以下のフィールドを持つ。**ブラッシュアップ後もこの構造に収まる形**で返してください。

| フィールド          | 意味                       | 現状の分量 | 深掘りの方向                                 |
| ------------------- | -------------------------- | ---------- | -------------------------------------------- |
| `title`             | レッスン名                 | 1行        | 原則維持（必要なら磨く）                     |
| `summary`           | 一覧用の要約               | 1行        | 維持                                         |
| `body[]`            | 本文（解説）               | 3段落      | **4〜5段落へ。背景・理由・現場の機微を厚く** |
| `keyPoints[]`       | この回のポイント           | 3点        | 3〜5点に精緻化                               |
| `tip`               | 現場のひとこと             | 1文        | 維持〜磨く                                   |
| `examples{ng,good}` | NG/Goodトーク例            | 各1        | 維持〜磨く                                   |
| `talkScript[]`      | 会話で学ぶ（注釈つき台本） | 3〜5往復   | **より実戦的に。注釈(note)で技術を言語化**   |
| `mistakes[]`        | よくある失敗→直し方        | 2件        | 2〜4件へ。現場で本当に起きる失敗             |
| `practice`          | この回の実践課題           | 1文        | 維持〜磨く                                   |
| `quizModuleId`      | 紐づく確認テスト           | -          | 設問の深掘り案も歓迎                         |
| `scenarioId`        | 紐づくロープレ             | -          | -                                            |
| `productIds[]`      | 差し込む商材ナレッジ       | -          | §4の正典に一致させる                         |

`talkScript` の各行：`{ role: "staff" | "customer", text: "...", note?: "技術解説" }`
`mistakes` の各件：`{ mistake: "失敗", fix: "直し方" }`

## 5. 絶対に守るルール（Non-Negotiables）

1. **事実を捏造しない。** 料金・還元・補償・仕様は §4 の公式URL＋最終確認日を正とする。不明・古い可能性のある数字は断定せず「要確認」と書く。**それらしい数字を勝手に置かない。**
2. **dカードGOLDの合計訴求**（割引約6,600円＋ポイント約12,000P＝年間約18,600円相当）と**PLATINUM切替の実質18,700円**は正典。勝手に変えない。
3. **コンプライアンス。** パスワード・認証コードは必ず「お客様ご自身が入力」。スタッフ代理入力の導線・表現を作らない。個人情報は本人と権限者のみ・最小限。
4. **絵文字は使わない。** 本文・台本・課題に絵文字を入れない。
5. **能動態・現場の言葉で。** 専門用語は噛み砕き、未経験者が読んで動ける具体性にする。
6. **押し売りにしない。** 「課題解決に伴走する」姿勢を崩さない。安さでなく「乗り換え後の生活」で語る。

## 6. ブラッシュアップしてほしい観点（深掘りの指針）

各レッスンについて、以下を意識して厚く・正確にしてください。

- **背景と理由（なぜそうするのか）**：手順だけでなく「なぜ効くのか」を未経験者に腹落ちさせる。
- **現場の機微**：お客様の心理、つまずきやすい瞬間、間の取り方など、実戦の質感。
- **会話の自然さ**：`talkScript` を、実際に口に出せるテンポ・言い回しに。`note` で「今のひと言が効く理由」を解説。
- **失敗の解像度**：`mistakes` を「あるある」で終わらせず、原因と具体的な立て直し方まで。
- **商材の正確さ**：§4の正典と一致。数字は公式リンクで裏取り、古い可能性は「要確認」。
- **一貫性**：STEP1→5で技術が積み上がる（ヒアリングで得た材料を提案・反論処理で再利用する等）。
